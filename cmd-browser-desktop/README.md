# CMD Browser PC

Base Electron pour Windows, macOS et Linux.

```sh
npm install
npm start
npm run build:win   # Windows
npm run build:mac   # macOS
npm run build:linux # Linux
```

**État :** squelette desktop uniquement. Les sites s'ouvrent actuellement dans le navigateur système. Pour un navigateur complet, il faut développer les onglets et les vues Web isolées, navigation, permissions et téléchargements. Les boutons Précédent/Suivant sont désactivés en attendant cette intégration. Aucune application n'a été compilée ni testée sur PC. Les exécutables doivent être signés pour une distribution fiable.
